Build the closed `iam.app-subject.onboarding-ready.v1` payload and append one immutable event plus one initial delivery intent for a first activation.

## Outputs and ownership

Own the event factory, the intent writer, the V11 migration function, and focused tests. Do not change activation state.

## Acceptance

- The payload is exactly the eight allowlisted fields, `activationState=ACTIVE`, `requiredProfileState=PROFILE_REQUIRED`.
- One logical onboarding version per activation; retries return the existing event without a second row.
- `outbox_event` and `outbox_delivery` are appended for the Dutch destination only.
- Envelope aggregate is `APP_ONBOARDING`, id = activation id, version = onboarding version.
- No global-identity lifecycle event is produced.
