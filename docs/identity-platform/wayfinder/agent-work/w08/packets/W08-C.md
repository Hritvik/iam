# W08-C — Compose and prove the first-activation transaction

## Objective

Compose prerequisite evaluation, activation, subject resolution and onboarding intent in one transaction and prove missing-evidence, retry, concurrency and rollback behaviour end to end.

## Authority and inputs

- Packets W08-A and W08-B (reviewed), [W-8 requirements](../../../work-items.md#w-8--activate-dutch-and-append-one-onboarding-intent), [D-10](../../../artifacts/implementation-decision-log.md), [D-11](../../../artifacts/implementation-decision-log.md).

## Outputs and ownership

Own the composing service, the end-to-end PostgreSQL test, the W-8 evidence artifact and the parent clean gate. Do not add relay or snapshot behaviour (W-9).

## Acceptance

- Missing any prerequisite leaves activation pending and appends nothing.
- First activation produces one App Subject, one ACTIVE activation and one logical onboarding version.
- Retry and concurrent activation add no subject, activation or event.
- Failure injected around state, event, delivery and audit boundaries rolls back all of them together.
- The stored event validates against the canonical payload schema and contains no global identity.
- No identity lifecycle event exists.
