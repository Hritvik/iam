## Outputs and ownership

Produce store operations that atomically consume the correct nonce and claim replay across every digest alias. Provide bounded cleanup without erasing immutable issuance audit. Own only `board.json` paths; W07-I owns the complete PostgreSQL matrix.

## Acceptance

- A resource nonce is issued durably and consumed atomically with replay claim.
- Fresh `jti` cannot reuse a consumed resource nonce.
- The same proof cannot replay after write-key rotation.
- A retained old key can consume an old nonce; removing it fails without mutation.
- Sequential, concurrent, and cross-instance claims have exactly one winner.
- Cleanup bounds expired/consumed nonce and replay rows while preserving required immutable audit.
- PostgreSQL time is authoritative; one-live-binding supersession is deterministic; cleanup batches are bounded to at most 1,000 rows.
- Every readable digest alias and key version participates in matching, while inserts use only the current write version.
- Focused tests cover insert-only and allowed transitions, NULL rejection, and exact function authority; W07-I owns the exhaustive migration and ACL matrix.
- SQL remains parameterized and functions retain fixed search path and least privilege.
