# W07-C — Bound external signing while transactional locks are held

## Objective

Guarantee that a stalled external signer cannot hold database locks or exhaust request and connection pools indefinitely.

## Authority and inputs

- [W-7 decisions](../../../artifacts/work-item-07-decisions.md)
- Security finding: signing occurred synchronously inside the local issuance transaction without an enforced deadline.

Input is the existing `TokenAccessIssuer`; output is a deadline-enforcing adapter with fixed safe failure. W07-E owns production wiring and configuration-bound validation.

## Acceptance

- The adapter rejects nonpositive or excessive deadlines; W07-E proves the enabled production-like wiring requires the bounded value.
- A signer completing before the deadline returns normally.
- A stalled or ignoring-interrupt signer yields one fixed safe failure within the bound.
- Timeout workers and queued tasks are bounded and do not accumulate across requests or context restart.
- Timeout propagates so W07-E rolls back code, nonce, replay, subject, and audit state.
- Provider details, token material, subjects, and global identity never enter errors or diagnostics.
