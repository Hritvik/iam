# W07-E2 — Remove worker-thread database access from token issuance

## Objective

Make the bounded signer path pure CPU/cryptography. The signing worker must not touch the database or hold a second
pooled connection while the request transaction owns one.

## Authority and inputs

- [W-7 decisions](../../../artifacts/work-item-07-decisions.md) — short issuance transaction; bounded external signer; security-context read on the request thread.
- W07-E reviews 01/02: identity-row self-block (fixed) and residual `canonical_registration()` call on the worker thread (open).
- Inputs: `ConsumedAuthorization`, `AppSubject`, security version, DPoP thumbprint, correlation, and the already-resolved `RegistrationManifest`.

## Outputs and ownership

- Carry the validated `RegistrationManifest` in `HumanAccessTokenIssueCommand`; `HumanAccessTokenIssuer` reads it from the command instead of `RegistrationRegistry`.
- Extend `TokenAccessIssuer.issue(...)` with the manifest so the orchestrator (which already resolved it on the request thread) supplies it across the async boundary.
- Replace the constant-true `AppSubjectBindingVerifier` in the issuer bean with a fail-closed sentinel; the orchestrator's in-transaction `activeSecurityVersion` read remains the sole authority.
- Remove the unused `DpopStateStore` parameter from the issuer bean.
- Own only the paths declared in `board.json`.

## Acceptance

- No collaborator reachable from `DeadlineTokenAccessIssuer`'s worker performs JDBC work.
- No `canonical_registration()` call occurs on the signing worker. The composition performs its request-thread reads as before (exchange resolution, V6 code consumption, V9 nonce and authority functions); the worker count is zero by unit test and static trace.
- The issuer rejects a command whose manifest does not match the authorization's app, client, resource, audience, or required DPoP.
- Deadlines and fixed failure messages are unchanged; rollback behaviour is unchanged.
- Unit tests prove a manifest-carrying command signs with a mocked registry that fails if touched. The full composed Spring bean graph is proven by W07-I's HTTP scenario, not here.
