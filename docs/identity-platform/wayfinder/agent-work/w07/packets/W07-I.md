- HTTP negatives include GET and PUT, encoded-path variants, wrong content type, query-confused form input, anonymous and secret client attempts, and every excluded OAuth/OIDC endpoint in the decision matrix.
- Token and resource nonce/replay tests cover sequential, concurrent, cross-instance, full-context restart, digest-key rotation/retention/removal, and cleanup.
- V8→V9 populated upgrade equals clean schema and preserves state; missing roles fail; owners, grants, function metadata, NULL arguments, constraints, and every table operation are literal matrices.

- Correlation, rate categories, errors, contracts, logs, metrics, diagnostics, database rows, audit, and outbox pass canary scans.
- The cross-packet diagnostic test seeds A/B/D-owned values together and proves serialization, `toString()`, logs, metrics, configured traces, database, audit, and outbox remain free of protected canaries.
- Full clean test, integration, contract, coverage, dependency, SBOM, secret, migration, and diff/conflict gates pass serially.
- Parent evidence states external signer/digest/distributed-limit/proxy obligations without claiming local production readiness.
- W07-I records an immutable evidence revision for both reviews. It does not update parent status; W07-F owns that final mutation after both reviews accept the same revision. Any correction reopens its owning packet, requires a fresh W07-I clean gate, and requires both reviews again.
