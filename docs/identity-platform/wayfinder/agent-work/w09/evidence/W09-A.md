## What was built

- `OutboxEnvelope`, `OutboxTransport` (+ retryable and non-retryable failures), `ClaimedDelivery`,
  `RelaySettings`, `RelayOutcome`, `OnboardingRelay`, `OutboxRelayRepository`,
  `JdbcOutboxRelayRepository`, `RelayException`.
- Claim uses the V2 `claim_outbox_deliveries` lease function (`skip locked`, bounded batch/lease);
  acknowledgement and quarantine use the V2 transition functions with the claimed version.
- Publish happens on the caller's thread after the claim commits; acknowledgement only follows a
  successful publish. A failed publish leaves the delivery leased, so it is redelivered after expiry.

## Acceptance mapping

| Criterion | Evidence |
|---|---|
| Bounded, concurrency-safe claim | repository bounds + two-connection claim one winner |
| Publish outside the state transaction; ack after success | unit redelivery test + mutation RED |
| Crash before ack is redelivered | lease-expiry integration test (attempt 2) |
| Bounded attempts and quarantine | unit exhausted/non-retryable cases; quarantine is terminal in integration |
