- Dutch uses Gradle, Spring Boot 3.4.5, Spring Authorization Server through the Boot starter, Spring JDBC/Security, Flyway, PostgreSQL, JUnit/Spring Test, Testcontainers 2.0.5, and JaCoCo.
- The IAM prototype has identity/identifier, authorization-code/PKCE, session/refresh-family, migrations, development identity, signing-key configuration, database-isolation, and persistence tests.
- The UMS prototype has a profile consumer, unique identity-to-member mapping, profile-state HTTP controller, correlation filter, standard error handling, migrations, and duplicate-delivery integration tests.
- The prototype contract currently exposes a global-looking `identityId` in `iam.identity.verified.v1`, UMS mapping events, and `/api/v1/me`; the settled design replaces that meaning with app-scoped `App Subject` and renames IAM onboarding to `iam.app-subject.onboarding-ready.v1` before portfolio adoption.

- The prototype uses H2 in part of IAM testing. The settled verification design requires PostgreSQL for persistence/migration/concurrency evidence; H2 is not evidence for those paths.
